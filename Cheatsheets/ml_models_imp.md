# Machine Learning Models - Quick Interview Cheat Sheet

## 1. Linear Regression
**Definition:** Predicts a continuous value (number) based on input features.

### Example
- Inputs (X): House size, bedrooms, location
- Output (Y): House price

**One-Liner:**
> Linear Regression learns the relationship between input features and a continuous target variable to predict numerical values.

---

## 2. Logistic Regression
**Definition:** Predicts a category/class instead of a number.

### Example
- Inputs: Study hours, attendance
- Output: Pass or Fail

**One-Liner:**
> Logistic Regression predicts the probability of a class and is mainly used for classification problems.

---

## 3. Decision Tree
**Definition:** Makes predictions by asking a series of if-else questions.

### Example
- Is age > 18?
- Is income > 50K?

**One-Liner:**
> Decision Tree splits data into branches using decision rules to make predictions.

---

## 4. Random Forest
**Definition:** Uses multiple Decision Trees and takes the majority vote or average.

**One-Liner:**
> Random Forest combines many decision trees to improve accuracy and reduce overfitting.

---

## 5. Support Vector Machine (SVM)
**Definition:** Finds the best boundary that separates classes.

**One-Liner:**
> SVM classifies data by finding the optimal hyperplane that maximizes the margin between classes.

---

## 6. K-Nearest Neighbors (KNN)
**Definition:** Looks at the nearest data points and predicts based on their labels.

**One-Liner:**
> KNN predicts a value or class based on the K most similar neighboring data points.

---

## 7. Naive Bayes
**Definition:** Uses probability to make predictions.

**One-Liner:**
> Naive Bayes predicts classes using Bayes' theorem while assuming features are independent.

---

## 8. K-Means Clustering
**Definition:** Groups similar data points together.

**One-Liner:**
> K-Means is an unsupervised algorithm that clusters similar data into K groups.

---

## 9. Principal Component Analysis (PCA)
**Definition:** Reduces the number of features while keeping important information.

**One-Liner:**
> PCA reduces dimensionality by transforming data into fewer informative components.

---

## 10. Neural Network
**Definition:** Learns complex patterns using interconnected layers of neurons.

**One-Liner:**
> A Neural Network mimics the human brain to learn complex relationships in data.

---

## 11. Gradient Boosting / XGBoost
**Definition:** Builds models sequentially, correcting previous errors.

**One-Liner:**
> XGBoost improves predictions by building trees one after another and learning from mistakes.

---

### Examples
- House Price

- Temperature

- XGBoost Regressor

Predicts a category.

### Examples

- Pass / Fail
- Fraud / Not Fraud

### Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- Naive Bayes
- KNN

---

### Examples
- Customer Segmentation
- Product Grouping

### Algorithms

- DBSCAN

---
