# 📘 AI/ML Tools Cheatsheet (updated)

## 🧠 Core ML/DL frameworks
- **TensorFlow / Keras:** High-level deep learning, production-ready
- **PyTorch:** Research-friendly, dynamic graphs
- **JAX:** High-performance autodiff and TPU-friendly
- **ONNX:** Interoperability for model export

---

## 📊 Classical ML
- **scikit-learn:** Algorithms + preprocessing
- **XGBoost / LightGBM / CatBoost:** Gradient boosting
- **Statsmodels:** Statistical modeling and inference

---

## 🖼️ Computer vision
- **OpenCV:** Classical CV toolkit
- **scikit-image:** Image processing utilities
- **Detectron2 / MMDetection:** Detection/segmentation frameworks
- **Albumentations:** Fast image augmentation

---

## 🔤 NLP and LLMs
- **Hugging Face Transformers:** Pretrained models and inference pipelines
- **Hugging Face Hub:** Model/dataset hosting, versioning, spaces
- **spaCy / NLTK / Gensim:** Industrial NLP, classic text processing

---

## 🧩 LLM orchestration and agents
- **LangChain:** Chains, tools, agents, retrieval; multi-provider LLM integration
- **LlamaIndex:** Retrieval-augmented generation (RAG) over your data
- **OpenAI / Azure OpenAI APIs:** Hosted LLM access for apps

---

## 🔎 Evaluation, observability, and experiment tracking
- **LangSmith:** Evaluate, trace, and monitor LLM apps
- **Weights & Biases (W&B):** Experiment tracking, sweeps, reports
- **MLflow:** Tracking, model registry, deployment
- **DVC:** Data/model version control

---

## 🤖 Reinforcement learning
- **OpenAI Gym / Gymnasium:** Environments
- **Stable Baselines3:** Implementations (PPO, DQN, etc.)
- **RLlib:** Scalable RL
- **PettingZoo:** Multi-agent environments

---

## 📐 Data handling and visualization
- **Pandas / NumPy:** Dataframes and arrays
- **Polars:** Fast DataFrame library
- **Matplotlib / Seaborn / Plotly:** Visualization

---

## ☁️ MLOps, deployment, and optimization
- **Kubeflow / Prefect / Airflow:** Pipelines and orchestration
- **BentoML / FastAPI / Gradio:** Serving and demos
- **ONNX Runtime / TensorRT:** Inference optimization
- **Ray:** Distributed compute for training/inference

---

## 🔗 Protocols and ecosystem glue
- **MCP (Model Context Protocol):** Standard for connecting models to tools, data, and apps
- **FAISS / Milvus:** Vector databases for retrieval
- **pgvector:** Vector search in PostgreSQL

---
