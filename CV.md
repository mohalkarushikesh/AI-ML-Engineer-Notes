# 📘 Computer Vision Cheatsheet

## 🧠 Core Concepts
- **Image Representation** → Pixels, channels (RGB, grayscale).  
- **Convolution** → Sliding filters to detect features.  
- **Pooling** → Downsampling (max/avg).  
- **Feature Maps** → Outputs of convolution layers.  
- **Activation Functions** → ReLU, Sigmoid, Softmax.  
- **Loss Functions** → Cross‑Entropy (classification), MSE (regression).  

---

## 🧩 Key Tasks
- **Image Classification** → Assign label to image.  
- **Object Detection** → Locate + classify objects (YOLO, Faster R‑CNN).  
- **Segmentation** → Pixel‑level classification (Semantic vs Instance).  
- **Image Generation** → GANs, Diffusion models.  
- **Image Enhancement** → Denoising, super‑resolution.  
- **Face Recognition** → Identity verification.  
- **Pose Estimation** → Detect human body joints.  

---

## ⚙️ Architectures
- **CNN (Convolutional Neural Network)** → Core building block.  
- **ResNet** → Skip connections for deep networks.  
- **VGG** → Simple stacked conv layers.  
- **Inception** → Multi‑scale convolutions.  
- **U‑Net** → Encoder‑decoder for segmentation.  
- **YOLO / SSD / Faster R‑CNN** → Object detection.  
- **Vision Transformers (ViT)** → Attention‑based CV.  

---

## 🛠️ Tools & Libraries
- **OpenCV** → Classic CV toolkit.  
- **scikit‑image** → Image processing.  
- **TensorFlow / Keras / PyTorch** → Deep learning frameworks.  
- **Detectron2** → Object detection/segmentation.  
- **Albumentations** → Data augmentation.  

---

## 📐 Evaluation Metrics
- **Classification** → Accuracy, Precision, Recall, F1.  
- **Detection** → mAP (mean Average Precision), IoU (Intersection over Union).  
- **Segmentation** → Dice coefficient, IoU.  
- **Generation** → FID, Inception Score.  

---

## 🚀 Workflow
1. Collect & preprocess images (resize, normalize, augment).  
2. Choose architecture (CNN, ResNet, ViT, etc.).  
3. Train with loss + optimizer.  
4. Evaluate with metrics.  
5. Tune hyperparameters.  
6. Deploy (API, mobile, edge device).
