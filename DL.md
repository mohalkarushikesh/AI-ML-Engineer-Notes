# 📘 Deep Learning Cheatsheet

## 🔑 Core Concepts
- **Neuron** → basic unit, computes weighted sum + activation.  
- **Layer** → collection of neurons (input, hidden, output).  
- **Activation Functions** → ReLU, Sigmoid, Tanh, Softmax.  
- **Loss Function** → measures error (MSE, Cross‑Entropy).  
- **Optimizer** → updates weights (SGD, Adam, RMSProp).  
- **Backpropagation** → gradient calculation for learning.  
- **Epoch / Batch / Iteration** → training cycle units.  

---

## 🧩 Architectures
- **Feedforward NN (MLP)** → basic dense layers.  
- **CNN (Convolutional Neural Network)** → image tasks.  
- **RNN / LSTM / GRU** → sequential data.  
- **Transformers** → attention‑based, NLP & beyond.  
- **GANs (Generative Adversarial Networks)** → generation tasks.  
- **Autoencoders** → dimensionality reduction, representation learning.  

---

## ⚙️ Training Essentials
- **Regularization** → Dropout, L2/L1, BatchNorm.  
- **Data Augmentation** → expand dataset (flip, rotate, noise).  
- **Learning Rate Scheduling** → adjust speed of training.  
- **Early Stopping** → prevent overfitting.  

---

## 📐 Evaluation Metrics
- **Classification** → Accuracy, Precision, Recall, F1, AUC.  
- **Regression** → MSE, MAE, R².  
- **Generative Models** → Inception Score, FID.  

---

## 🛠️ Libraries & Tools
- **TensorFlow / Keras** → high‑level DL.  
- **PyTorch** → flexible, research‑friendly.  
- **JAX** → high‑performance autodiff.  
- **ONNX** → model interoperability.  

---

## 🚀 Workflow
1. Collect & preprocess data  
2. Define architecture  
3. Choose loss + optimizer  
4. Train (forward pass + backprop)  
5. Evaluate metrics  
6. Tune hyperparameters  
7. Deploy model  

---
