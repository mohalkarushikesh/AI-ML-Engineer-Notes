Domain-leveraged projects (your differentiator)
- **Audit-risk / fraud detection is the natural fit.** Take a public dataset (IEEE-CIS Fraud Detection or the credit-card fraud set on Kaggle) and build a classifier that flags high-risk transactions or returns. This lets you show feature engineering, handling class imbalance, and proper evaluation (precision/recall, not just accuracy) — and you can talk about it fluently in interviews because you understand the domain.
- **Tax-document intelligence is a great deep-learning project.** Extract structured fields (amounts, dates, payer/payee) from documents like invoices, W-2s, or 1099s using something like LayoutLM or Donut, or a CNN+OCR pipeline. Document understanding is in high demand and directly maps to what tax/finance teams need.
LLM / NLP (currently the hottest area)
- **Build a RAG-based Q&A system over tax regulations** or a set of financial documents — chunk the docs, embed them, retrieve, and answer with citations. This demonstrates you can work with modern LLM tooling (embeddings, vector stores, prompt design), which is what a lot of AI/ML hiring is actually about right now.
