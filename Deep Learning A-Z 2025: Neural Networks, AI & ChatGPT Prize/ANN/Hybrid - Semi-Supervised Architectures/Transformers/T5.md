**T5 (Text-to-Text Transfer Transformer) is a landmark NLP model introduced by Google Research in 2019 that reformulates every language task—translation, summarization, question answering, classification—into a unified text-to-text format. It uses an encoder-decoder Transformer architecture and was trained on the massive “Colossal Clean Crawled Corpus” (C4).**

---

## 📘 Overview
- **Full Name:** Text-to-Text Transfer Transformer (T5)  
- **Introduced by:** Google Research, October 2019  
- **Core Idea:** Treat all NLP tasks as text-to-text problems (input text → output text).  
- **Architecture:** Encoder-decoder Transformer (similar to seq2seq models).  
- **Training Corpus:** C4 dataset (~750GB of cleaned Common Crawl text).  
- **License:** Apache 2.0, open-source implementation available.  

---

## 🏗️ Architecture Breakdown
- **Encoder:** Processes input text into contextual embeddings.  
- **Decoder:** Generates output text token by token.  
- **Attention Mechanism:** Self-attention in encoder, cross-attention in decoder.  
- **Positional Encoding:** Captures word order in sequences.  
- **Unified Task Format:**  
  - Example:  
    - Translation → “translate English to German: Hello world” → “Hallo Welt”  
    - Summarization → “summarize: The article discusses…” → “Key points…”  
    - Classification → “cola sentence: The cat sat on the mat” → “acceptable”

## ⚡ Key Innovations
- **Unified Framework:** One model for multiple NLP tasks.  
- **Scalability:** Trained with billions of parameters (T5-Base, T5-Large, T5-3B, T5-11B).  
- **Pre-training Objective:** “Span corruption” — mask random spans of text and predict them.  
- **Fine-tuning:** Task-specific prompts guide the model to perform diverse tasks.  
- **Flexibility:** Works across translation, summarization, question answering, sentiment analysis, etc.

## 📊 Model Variants
| Version | Parameters | Use Case |
|---------|------------|----------|
| **T5-Small** | 60M | Lightweight tasks, experimentation |
| **T5-Base** | 220M | General NLP tasks |
| **T5-Large** | 770M | Higher accuracy, more compute |
| **T5-3B** | 3B | Advanced NLP tasks |
| **T5-11B** | 11B | State-of-the-art performance |

---

## 🌍 Importance & Legacy
- **Benchmark Results:** Achieved state-of-the-art on GLUE, SuperGLUE, and other NLP benchmarks.  
- **Influence:** Inspired later models like FLAN-T5 (instruction-tuned), PaLM, and LLaMA.  
- **Applications:**  
  - Machine translation  
  - Text summarization  
  - Question answering  
  - Sentiment analysis  
  - Dialogue systems
