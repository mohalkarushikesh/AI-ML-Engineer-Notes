# 💬 Course 4: NLP - Natural Language Processing with Python

## 📘 Overview
Learn how to apply **Machine Learning, SpaCy, NLTK, Scikit-Learn, and Deep Learning** techniques to process and analyze text data effectively.

---

## 🚀 What You Will Learn

- Work with text files using Python  
- Process and extract data from PDF files  
- Use Regular Expressions for pattern matching  
- Perform fast tokenization with SpaCy  
- Apply Stemming and Lemmatization  
- Vocabulary matching using SpaCy  
- Part-of-Speech (POS) Tagging  
- Named Entity Recognition (NER)  
- Visualize POS and NER results  

---

## 🤖 Machine Learning & NLP

- Text Classification with Scikit-Learn  
- Topic Modeling with:
  - Latent Dirichlet Allocation (LDA)  
  - Non-negative Matrix Factorization (NMF)  
- Word2Vec embeddings  
- Sentiment Analysis using NLTK  

---

## 🧠 Deep Learning

- Build a chatbot using Deep Learning  

---

## ✅ Summary
A complete course covering **text preprocessing, NLP techniques, machine learning, and deep learning applications** using Python.
